STEP 0 Claude Codeをまだ入れていない方へ（すでにお持ちの方は読み飛ばしてOK） ▾

Claude Codeは、Anthropic公式が配っているインストールコマンドで入れられます。お使いのOSに合わせて、どちらか1行をターミナルに貼り付けてください。インストール後、初めて「claude」と打って起動したときにブラウザが開き、ログインを求められます。案内に沿って進めばOKです。

Mac・Windowsどちらも対応無料でインストールできる初回起動時はブラウザでログイン使うにはPro以上のプラン登録が必要
Macの場合（ターミナル）▾ 
curl -fsSL https://claude.ai/install.sh | bash
Windowsの場合（PowerShell）▾ 
irm https://claude.ai/install.ps1 | iex
1
拡張① ／ ブラウザ操作
playwright — Claude Codeにブラウザを操作させる

ブラウザ操作を自動化するMCPサーバーです。入れておくと、インスタのリサーチやWebサイトの動作確認まで、Claude Codeに任せられるようになります。
使い方：導入後は、Claude Codeへの指示に「このサイトを開いて確認して」「〇〇を調べて」のように伝えるだけです。あとは自動でブラウザを操作してくれます。

Microsoft公式ブラウザ操作を自動化調査作業を短縮
ターミナルに貼るコマンド▾ 
claude mcp add playwright npx @playwright/mcp@latest

公式情報：Playwright公式ドキュメント

2
拡張② ／ デザイン品質
frontend-design — AIっぽくないデザインにする

LPやWebサイトを作らせたとき、いかにも「AIが作った」印象になりがちなデザインを、独自性のある仕上がりに寄せてくれる拡張です。
使い方：特別な操作は不要です。いつも通り「LPを作って」「UIを作って」と頼むだけで、裏側で自動的に働いて仕上がりの質を底上げしてくれます。

Anthropic公式27万件以上インストールUI生成時に自動で働く
ターミナルに貼るコマンド▾ 
/plugin marketplace add anthropics/claude-code
/plugin install frontend-design@claude-code-plugins

公式情報：Anthropic公式リポジトリ

3
拡張③ ／ 相談役
claude-code-setup — プロジェクトの伸びしろを教えてくれる

いま触っているプロジェクトを読み取り、「ここは自動化できます」「この機能を追加した方がいいです」と提案してくれます。ファイルを書き換えることはない、読み取り専用の拡張です。
使い方：「このプロジェクトにおすすめの自動化を教えて」のように話しかけるだけです。提案されたものを実際に入れるかどうかは、そのつど自分で判断できます。

Anthropic公式読み取り専用で安全使い方の提案だけしてくれる
Claude Codeに話しかける言葉▾ 
このプロジェクトにおすすめの自動化を教えて

公式情報：Anthropic公式プラグインページ

4
拡張④ ／ 開発フロー
Superpowers — いきなり作業せず、段取りしてから動く

要件整理→設計→実装→テストという、本来の開発の流れに沿ってClaude Codeが進めてくれるようになる拡張です。思いつきで実装が始まって手戻りする、を防いでくれます。
使い方：導入後は、普段通り「〇〇を作って」「このバグを直して」と頼むだけです。段取りしてから動く、という進め方に自動的に変わります。

開発者コミュニティ製開発フローを型化手戻りを減らす
ターミナルに貼るコマンド▾ 
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

公式情報：開発者（obra氏）公式リポジトリ

5
拡張⑤ ／ 安全性
security-guidance — 危ないコードを未然に防ぐ

Claude Codeが書いたコードに、インジェクションなど危険な書き方が紛れていないかを自動でチェックしてくれます。特別な操作は不要で、入れておけば裏側で動き続けます。
使い方：特にありません。入れておくだけで、コードを書くたびに自動でチェックが走り、見つかればその場で教えてくれます。

Anthropic公式脆弱性を自動検知導入後は放置でOK
ターミナルに貼るコマンド▾ 
/plugin install security-guidance@claude-plugins-official

公式情報：Anthropic公式ドキュメント

コマンドは公式のものだけを掲載しています。
このページのコマンドは、2026年8月時点で公開されている各拡張の公式手順をもとにしています。仕様が変わっている場合は、拡張の名前で検索し直してください。
全部入れても、いつもの使い方は変わりません。
5つとも「追加で使えるようになる機能」なので、普段の指示の仕方はそのまま使えます。合わないと感じたら、外すのも簡単です。
